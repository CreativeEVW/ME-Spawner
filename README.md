# MESpawner

An **Applied Energistics 2 (AE2)** addon mod for **Minecraft 1.21.1** on **NeoForge**.

## About

MESpawner adds an **ME Spawner** — a machine that connects to your ME network, reads a spawn egg's loot table, and generates mob drops directly into your network storage.

## Features

- **ME Spawner Block**: Connects to ME network, reads spawn egg loot tables
- **Direct Network Storage**: Drops are inserted directly into ME storage
- **Upgrade Cards**: Probability Card, Looting Card, Acceleration Card
- **Energy Integration**: Draws AE power directly from the ME network
- **Configurable**: Energy cost per operation

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.230+
- Applied Energistics 2 19.2+

## Getting Started

1. Place the ME Spawner and connect it to your ME network
2. Insert a spawn egg to select the mob type
3. Install upgrade cards to boost output
4. The machine will process loot tables every 10 seconds (with speed cards reducing this)
