# 刷怪笼控制器 (Spawner Controller)

<BlockImage id="spawner_controller" scale="8" />

**单个 AE 网络内仅允许一台生效**：同网络存在多台时，坐标最小的一台生效，其余无效——纹理熄灭、Jade 显示红色"控制器冲突"、GUI 同步显示红色提示。

## 功能

接管网络中所有「存储模式 = 输入AE」的 ME刷怪笼产物：

| 状态 | 行为 |
|------|------|
| 过滤空白 + 无反相卡 | 不过滤，产物全部从控制器自己的输出路由送出 |
| 过滤空白 + 反相卡 | **全部销毁**（不生产） |
| 有过滤 + 无反相卡（白名单） | 销毁**不匹配**的物品 |
| 插入反相卡（黑名单） | 销毁**匹配**的物品（过滤空白则全部通过） |
| 销毁 + 溢出销毁卡 | 销毁量 1:1 转化为[经验晶体](experience_crystal.md)，从控制器输出；无卡则丢弃 |
| 抢夺卡 | 全部产物数量 × 控制器抢夺倍率（取倍率最高的 3 张乘积） |

刷怪笼存储模式为「相邻容器」时，控制器**不干预**。

## GUI（存储总线同款）

- 配置槽：9 列，基础 2 行；插入容量卡后解锁全部（共 7 行 63 格）
- 清空按钮（×）：清除全部标记
- 支持从 JEI 拖拽物品标记；内存卡可保存/加载标记（潜行右键保存、右键加载）

## 升级卡（6 槽）

| 槽位 | 卡 | 最大数量 | 效果 |
|------|-----|----------|------|
| 1 | 反相卡 | 1 | 切换为黑名单模式 |
| 2 | 容量卡 | 1 | 解锁全部配置槽 |
| 3 | 溢出销毁卡 | 1 | 销毁产物转化为经验晶体 |
| 4-6 | 抢夺卡系列 | 3（有效） | 产物倍率 ×2/×6/×9，取最高的 3 张乘积 |

## 能量

与 ME刷怪笼一致：2M AE 私人缓存 + FE 输入（1 AE = 2 FE）。
